# 绿色收益与入口页（GREEN）

> 本文只讲**新增模块**的口径。原有阴影路线的算法口径见 `docs/DATA-SOURCES.md`，
> 交付与验收见 `README.md`。新增模块不改动原有代码，隔离边界写在 §4。

---

## 1. 这个模块回答什么问题

用户在路线页选完起终点后，页面上多出一个「绿色收益」面板，回答三件事：

| 问题 | 输出 | 依赖的输入 |
|---|---|---|
| 这段路改成步行/骑行，**少排多少二氧化碳**？ | `少排放`，单位克或千克 | 路线米数 × 对比基准因子 ÷ 载客人数 |
| 这段路**烧掉多少大卡**（健身可用）？ | `净消耗热量`，单位大卡 | 路线米数 ÷ 速度 → 分钟 × MET × 体重 |
| 为了阴凉**多走的那几十米**值多少？ | 多花的分钟与净大卡 | 两条路线的米数差 |

三件事都由**同一条数据链**驱动：路线长度不是重新算的，而是**读页面已有的 `#fast-len` / `#cool-len`**
（见 §4），所以面板上的米数永远和上面的卡片一致，不会出现"上面 1113 米、下面按 1120 米算"。

## 3. 公式与单位口径

### 3.1 时长

```
分钟 = 米 ÷ (速度 km/h × 1000 ÷ 60)
```

步行的**默认速度直接取本站算路常量** `CORE.WALK_SPEED = 1.25 m/s = 4.5 km/h`，不另起炉灶。
这条契约由断言盯着：`js/core.js` 里 `WALK_SPEED` 一旦被改，`smoke-green.js` 立刻红
（断言名："js/core.js 的 WALK_SPEED 仍是 1.25 m/s"）。1113 米 @4.5 km/h = **14.84 分**，
和 README §1 的"最快路线 14.8 分钟"是同一个数——不是巧合，是同一套速度。

### 3.2 热量

对外报告只用 **ACSM 口径**：

```
kcal/min = MET × 3.5 × 体重kg ÷ 200          （1 MET = 3.5 ml O₂/(kg·min)，1 L O₂ ≈ 5 kcal）
总消耗   = kcal/min × 分钟
净消耗   = 总消耗 − 同等时长静坐（1 MET）      ← 面板上显示的是这个
```

业界还有一条速算口径 `kcal = MET × 体重kg × 小时`。两条**不是谁对谁错，是定义差**：

```
(3.5 / 200) ÷ (1 / 60) = 60 × 3.5 / 200 = 1.05
```

即 ACSM 口径比速算口径高**整 5%**。这个 1.05 是精确常数，被断言锁死：
"热量两条口径的固有差精确等于 5%（1.05 倍），当常数锁死"。谁单方面改了公式，
`compute()` 会立刻在面板上打出警告而不是静默偏移 5%。

**为什么显示"净消耗"而不是"总消耗"**：运动手表多报总消耗，健身语境下"这次活动多烧了多少"
才是可比的。所以净消耗 = 减去同等时长静坐，并且界面上单独列了一条"同等时长静坐只耗 X 大卡"，
让口径自己说明自己。两者差多少，用户看得见。

### 3.3 减排

```
每人每公里排放 = 因子                               （unit = passenger.km，已摊到每人）
每人每公里排放 = 因子 ÷ 载客人数                     （unit = vehicle.km，一辆车跑一公里）
少排放 = (每人每公里排放 − 本次动作直接排放) × 公里数
```

**单位混用是这块最容易出错的地方**：DEFRA 表里小汽车给的是 `km`（车辆公里），
出租车/公交/铁路给的是 `passenger.km`（人公里）。把公交的 `0.12999 passenger.km`
再除一次载客人数，就会把公交算便宜好几倍。所以：

- 每条基准在数据表里**必须带 `unit`**；
- 遇到不认识的 `unit`，`perPersonFactorKg()` **返回 null**，面板显示提示而不是猜；
- `passenger.km` 的基准在界面上**自动隐藏载客人数控件**（有断言盯这条）。

步行/骑行的直接排放写死 `0`。**没有**把"多走路要吃饭、吃饭要排碳"折进结果
（文献典型 0.005–0.035 kg CO₂e/人公里），只在免责里点名。折进去会把减排量抹掉一大截，
但那是另一个口径，不该偷偷做。

### 3.4 示意换算（都标了"示意"）

| 换算 | 依据 | 状态 |
|---|---|---|
| 步数 = 米 ÷ 0.65 m | 步幅按 1.65 m × 0.4 估 | 未核原始人体测量数据；骑行时不报步数 |
| 苹果克数 = 净大卡 ÷ 52 × 100 | 苹果可食部 52 kcal/100 g | 文献常见值，未核原始成分表 |
| 树·年 = 减排千克 ÷ 21.8 | 成年树一年固碳约 21.8 kg | 纯示意，只为可读性 |
| 年累计 = 单次 × 每周趟数 × 32 周 | 32 周 ≈ 一学期 + 假期 | 假设，界面上可调每周趟数 |

## 4. 与原有代码的隔离边界（可验证，不是口头承诺）

| 边界 | 怎么做到的 | 哪条断言盯着 |
|---|---|---|
| 不改原有 JS | 新逻辑全在 `green-core/green-ui/textfx/home` 四个新文件 | `原有 12 个脚本标签一个都没少` |
| 不改原有 DOM 内容 | 面板只**读** `#fast-len`/`#cool-len`/`#delta` 的文本 | `green-ui.js 不写原有页面节点` |
| 不劫持原有事件 | 只 `MutationObserver` 观察 + 自己控件监听；不碰 `#time`/`#start`/`#end` | `没有新增任何 window 级监听器` |
| 不覆盖原有全局 | 只新增 5 个全局名 | `基线沙箱里本来没有绿色模块的 5 个全局名` + `只新增…五个全局` |
| 不影响原有计算 | 同一条数据链跑**两个沙箱**，一个不带绿色模块当基线，13 个输出字段逐项比对 | `原有页面输出文本一字未变（13 个字段全等）` |
| 页面结构不写死进 HTML | 面板运行时插入 | `面板结构没被写进 index.html` |

集成断言的做法值得记一笔：**不是"看起来没坏"，而是拿基线逐项 diff**。
带模块与不带模块跑完 `APP.redraw()` 后，`#fast-min`/`#cool-sun`/`#delta` 等 13 个字段
必须完全相等，`#panel` 只能多 1 个子节点，`window` 监听器列表必须一模一样。

## 5. 数据来源（全部可回溯）

### 5.1 交通排放因子：英国官方 2024 版转换因子

- 出处：**UK BEIS/DEFRA/DSU Greenhouse gas reporting: conversion factors 2024**，
  Condensed set v1.1（2024-07-08 发布，2024-10-30 因舍入误差更新过一批因子）
  <https://www.gov.uk/government/publications/greenhouse-gas-reporting-conversion-factors-2024>
- 取数方式：**下载官方 xlsx，用 openpyxl 直接读 `Passenger vehicles` 表**，不抄二手转述。
  每条因子在 `data/green-factors.js` 里都写了 `ref`（表名 + 分组 + 行号）。

| 基准 | kg CO₂e | 单位 | 原表位置 |
|---|---|---|---|
| 小汽车（平均） | **0.16984** | vehicle.km | Cars (by size) · Average car · 第 54 行 |
| 小汽车（大型） | 0.20729 | vehicle.km | 第 52 行 |
| 小汽车（小型） | 0.13994 | vehicle.km | 第 48 行 |
| 摩托车（平均） | 0.11367 | vehicle.km | 第 66 行 |
| 出租车 | 0.14861 | passenger.km | Taxis · Regular taxi |
| 市内公交 | 0.12999 | passenger.km | Bus · Local bus (not London) |
| 长途大巴 | 0.02717 | passenger.km | Coach |
| 城际铁路 | 0.03546 | passenger.km | Rail · National rail |
| 轻轨/有轨 | 0.0286 | passenger.km | Rail · Light rail and tram |

**地域偏差必须主动说**：这是英国因子。中国大陆的车队结构（SUV 占比、柴油占比、载客率）
与电网结构都不同，量级可用，绝对值有偏差。界面上的免责第一条就是这句。

### 5.2 交叉验证：美国 EPA

<https://www.epa.gov/greenvehicles/greenhouse-gas-emissions-typical-passenger-vehicle>

EPA 公布：燃烧 1 加仑汽油 = **8,887 g CO₂**；典型乘用车每英里 **400 g CO₂**（8887 ÷ 22.2 mpg）。
换算：400 g/mile ÷ 1609.34 m/mile = **248.5 g/km**（单车、仅尾气）。
DEFRA 平均小汽车 = **169.8 g/km**。两者相差 **1.46 倍**。

差在哪：EPA 只算尾气、不含 CH₄/N₂O 的 CO₂e 折算，但美国车队里大车占比更高；
DEFRA 是含 RM 的 CO₂e、按英国车队平均。**这是口径差异，不是谁抄错了**——
面板的来源折叠区里把两个数并列写出来，就是为了让别人一眼看到这个差异并当场解释。

### 5.3 MET 档位：**未在线核对，已标 pending**

`Compendium of Physical Activities`（Ainsworth 等 2011 修订版）本次**没能访问原始表格**
（会话内网络对 wikipedia / hhs.gov / bu.edu / cmptrend 全部失败，只有 gov.uk 与 epa.gov 可达）。
因此：

- 数据里 `sources.met.verify = "pending"`，界面免责点名"未能在线核对原表"；
- 所有 MET 档位都在界面上**可读可改**（速度强度下拉直接显示 MET）；
- 断言只锁**内部一致性**（MET 随速度单调递增、默认档位与默认速度一致），
  **不**把某个 MET 值当权威锁死。

用的档位（可改）：步行 3.2/4.0/4.5/5.5 km/h → MET 2.5/3.0/3.3/4.3；
骑行 12/15/19/22 km/h → MET 4.0/6.0/8.0/10.0。

## 6. 已知偏差与"不做"的清单

1. **不吹减排实测**：校园短途多数本来就不开车，面板说的是"**假设这段路改成乘车**"的上限。
2. **不计食物能耗**的间接排放（会抵掉一部分减排，口径不同，只写说明）。
3. **不计车辆制造与轮胎磨损**（步行/骑行按直接 0 排放）。
4. **骑行按整段可骑估**：南校园部分路段禁骑/需推行，数据表里 `campusNote` 写了这条。
5. **英国因子代替中国因子**：量级可用，绝对值有地域偏差。
6. **32 周/年的累计是假设**：可调每周趟数，但周数是默认值。
7. 载客人数只支持 1 / 1.5 / 2 / 3 这几个整数与半数档，不做"实际同乘人数分布"建模。

## 7. 入口界面（home.html）

- 结构：主视觉（乱码解码站名 + 打字机结论）→ 4 个结论数字 → 绿色收益预告（步行/骑行可切）
  → 3 张功能卡 → 楼名跑马灯 → 页脚来源。
- **页面里没有写死任何一个数字**：少晒分钟、多走米数、阴影覆盖率、减排、大卡、步数、
  年累计、楼名、演示日期、校园名、校园面积全部由 `data/*.js` + `CORE` + `GREEN` 现场算出来。
  断言逐条比对 DOM 文本与函数返回值（如 `入口页"少晒"取自 14:00 帧两条路线的真实差值`）。
- 只加载 `meta.js` / `routes.js` / `basemap.js` / `green-factors.js`（合计 **101.1 KB**），
  **不加载 861.6 KB 的 shadows.js** 和 101.2 KB 的 graph.js —— 有断言守着，防止有人顺手把全量数据
  塞进入口页拖慢首屏。
- 动效库 `js/textfx.js` 每条效果都先判 `prefers-reduced-motion`：命中就直接落终值，
  不留半截动画、不留 JS 定时器。两个 CSS 文件里也各写了一份 `@media (prefers-reduced-motion)`。

## 10. 答辩时被问到就照这段说

**三句话版本**

> 减排量我用的是英国政府 2024 年官方转换因子，直接下载官方 xlsx 逐行读出来的，
> 平均小汽车 0.16984 kg 每车辆公里，表里每条我都写了行号。
> 热量是 MET × 体重 × 时间，报的是**减去同等时长静坐的净消耗**，不是手表那种总消耗。
> 这两块我都是按"假设这段路改成乘车"的上限算的，食物能耗、车辆制造都还没计进去。

**会被追问的四个问题**

| 追问 | 答 |
|---|---|
| 为什么不用中国因子？ | 手上能当场核对到原文的权威表是 DEFRA 2024；中国缺一份同等粒度、能公开下载的乘客公里因子表。所以我用了英国因子并把地域偏差写在免责第一条和界面第一行。 |
| 0.16984 和 EPA 的 0.2487 差这么多，哪个对？ | 都对，口径不同。EPA 是仅尾气 CO₂、美国车队；DEFRA 是含 CH₄/N₂O 折算的 CO₂e、英国车队。我把它俩都摆在来源折叠区里，差 1.46 倍，不是抄错。 |
| MET 从哪来？ | Compendium 的典型档位，本次网络没能打开原表核对，所以界面里把速度档位和 MET 都做成可见可调，免责里点名 pending。 |
| 多走 44 米也减排吗？ | 不减。多走只多花时间与大卡，我在文案里明确写了"这部分不换算成减排"，就是为了不拿 44 米去凑碳。 |
